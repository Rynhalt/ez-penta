## Critical known results (provisional scientific interpretation)

- Original Dataset2: 320 source seeds; 21,184 assigned prompts; 17,795 complete responses; 3,387 truncated; 2 empty. Prior technical audit recovered 17,373 binary response judgments from saved guard outputs (not human labels).
- Pipeline 1: 4,069 analysis-eligible harmful rows outside heldout; US culture vs neutral pooled Mantel–Haenszel odds ratio **1.982**, 95% CI **1.583–2.482**, reported p **2.21e-9**; Japan culture vs neutral OR **1.097**, p **0.487**. Repeated observations per source seed require seed-aware uncertainty before strong inference.
- Pipeline 2: SafeTune refusal-direction probes on ~8 prompts/condition; activation p about .09–.10 within language, .48/.86 cross-language. Hypothesis-generating, not causal localization.
- Pipeline 3: 22 CuratorKIT-generated preference-shaped rows, not human approved. Self-generated by Tiny Aya; do not call them validated gold data.
- Pipeline 4: 22 chosen responses used for one-epoch **SFT** (rejected data not used in objective); restricted LoRA 417,792 trainable parameters at layers 18 and 23 and broad LoRA ~30.2M. `pipeline4_results.json` lists merged checkpoint locations under `/content`, not durable adapters.
- Pipeline 5: only baseline vs restricted model evaluated on 40 prompts: baseline 39 Safe / 1 Unsafe; restricted 37 Safe / 2 Unsafe / 1 Controversial. No demonstrated improvement. Crucial mismatch with prior GGUF work: max output **192** tokens and input tokenizer truncation **1024** tokens, vs original GGUF output cap **1024** and context **8192**. The model and guard also used different HF/GGUF backends.
- **Newly confirmed:** CircuitKIT *has* an experimental `cohere2` TransformerLens compatibility port, including `CohereLabs/tiny-aya-water`, with real-weight parity and discovery tests. Upstream TransformerLens alone lacks `cohere2`; that does NOT prove CircuitKIT is blocked. First run CircuitKIT's explicit compatibility tests.

## What counts as completion

Completion is **not** a positive safety result. Completion is a verified, reproducible outcome with all available baselines, diagnostics, statistically appropriate uncertainty, mechanistic attempts and causal tests where technically feasible, and an honest limitations report. If experimental evidence is weak or a necessary human labeling step is unavailable, preserve the negative/inconclusive result and state exactly what is blocked. Never manufacture significance or claim CircuitKIT ran when it did not.

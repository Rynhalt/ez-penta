# Post-training experiments

| Directory | Role |
| --- | --- |
| `arm_ja/` | Existing Japanese-arm execution notebooks, source helpers, checkpoints, audit receipts and logs |
| `japan_culture/` | Japan/US cue transfer evaluation and interim analyses |
| `reports/source_data/` | Saved machine-readable aggregates used by the canonical article's charts |

Start with the [article](../reports/experiment_report.md) and [experiment artifact map](../reports/EXPERIMENT_ARTIFACT_MAP.md). The [Japan-culture report](japan_culture/INTERIM_REPORT.md) is interim and must not be represented as a final six-chunk result.

The arm directories retain their paths because execution helpers and Drive synchronization encode them. Source JSON files, checkpoint directories and DONE manifests were not rewritten by repository reorganization. Many EN/BI/steering artifacts are stored on Drive; their exact locations and access limitations are documented in the artifact map.
